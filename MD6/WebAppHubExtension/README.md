# WebApp Hub Speed Dial

Chrome の新しいタブに、Web サイト、HTML アプリ、React JSX アプリを並べられる拡張機能です。

## インストールと起動ページ

1. リポジトリを ZIP でダウンロードして展開するか、`MD6/WebAppHubExtension` フォルダーを丸ごとコピーします。ビルドや追加のインストールは不要です。
2. Chrome で `chrome://extensions/` を開き、デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が直下にある `MD6/WebAppHubExtension` フォルダーを選びます。
4. 新しいタブを開くとスピードダイヤルが表示されます。Chrome の起動時にも表示するには、`chrome://settings/onStartup` で「新しいタブページを開く」を選びます。特定のページとして指定する場合は、拡張機能の「設定」に表示されるアドレスを使用します。

「設定」の「リンクとアプリを開く場所」で、同じブラウザータブまたは新しいブラウザータブを選べます。ホームでアプリとサイトをまとめて表示するか、別々のタブにするかも選べます。分ける場合は最初に表示する種類と、左側に置くタブを個別に設定できます。

## タイルとフォルダー

「＋ フォルダー」で作成できます。クリックするとホームの上にポップアップで中身を表示します。タイルをフォルダーにドラッグするか、編集画面の「フォルダー」で所属を変更できます。タイルの端へのドラッグか、タイル上の矢印で並び替えできます。フォルダーを解除すると、中のタイルはホームに戻ります。タイル画像は URL、画像ファイル、編集画面への画像の貼り付けで登録できます。Web サイトの画像はタイルの横幅を使って表示し、HTML・JSX アプリの画像はブラウザータブのアイコンにも使われます。

## 登録と移行

- Web サイトは `https://` または `http://` で始まる URL を登録できます。
- HTML と JSX はファイルを選ぶか、コードを貼り付けて登録します。JSX のルートは `export default` または `App` で指定します。React、ReactDOM、Lucide のランタイムを同梱しています。アプリ固有の依存関係や相対ファイルは、単体 HTML にまとめるかアプリから参照できる URL を使います。
- 設定から MD6 の JSON バックアップを読み込めます。アプリのコード、名前、アイコン、表示順とグループを取り込みます。MD6 側の GitHub 連携設定、トークン、各アプリの保存データは移行対象外です。
- Speed Dial 2 の JSON も設定の読み込み欄で自動判別します。リンク名、URL、グループ、保存された配置順、利用できるサムネイルを取り込みます。HTTP・HTTPS 以外のリンクはスキップし、閲覧回数やテーマは引き継ぎません。既存のタイルに追加します。
- アプリを実行する場所は拡張機能の設定画面から分離されています。アプリの `localStorage` の基本メソッドで保存した値は、同じアプリを再度開いても残ります。IndexedDB や同一オリジンを必要とするブラウザー機能は、実行環境の違いにより動作が異なる場合があります。

同梱ライブラリは React と ReactDOM 18.3.1、Babel Standalone 7.26.9、Lucide 0.468.0 です。ライセンスは `vendor/licenses/` にあります。
