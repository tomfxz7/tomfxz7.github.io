# WebApp Hub

HTML / React アプリを保存して開く、ブラウザー内のホーム画面です。

- タイルの左右の端にドラッグすると、その前後へ移動します。自動ソート中に動かした場合も、表示中の順序を保って「手動並び替え」に切り替わります。
- アプリを別のアプリの中央へ重ねるとグループを作成します。グループの中央へ重ねると、そこへ追加します。
- グループを開くと、名前変更、内部の並び替え、グループ解除ができます。解除してもアプリは削除されず、その場所に並びます。
- タイルの十字矢印「移動・グループ化」メニューでも、配置場所の選択、グループ間の移動、グループ作成ができます。スマホやキーボードではこちらを使えます。
- グループ内のアプリは移動メニューや下部のドロップ枠からホームへ戻せます。空になったグループは自動で消えます。

配置・グループ名・グループ内順序・並び順の設定は、アプリと一緒に IndexedDB に保存します。新しい JSON バックアップ（version 2）にもこれらを含めます。一部のアプリのみをエクスポートした場合は、そのアプリの配置と所属だけを残します。

上書きインポートはバックアップの配置と設定を復元します。追加インポートは既存の表示順を保ち、読み込んだタイルを後ろに追加します。同じバックアップを繰り返し追加してもIDは重複しません。旧形式の配列JSONも読み込めますが、ソート設定が入っていないため配列順で復元します。

## ローカル起動とテスト

リポジトリのルートで `python3 -m http.server 8000` を起動し、`/MD6/` を開きます。ビルドは不要です。通常の表示には Tailwind CSS と Lucide の CDN 接続が必要です。

回帰テストには Python の `playwright` と Chromium が必要です。

```sh
python3 -m pip install playwright
python3 -m unittest discover -s MD6/tests -v
```

Chromium が PATH にない場合は `CHROMIUM_PATH` を指定してください。テストは実際のページ・ドラッグ操作・IndexedDB・ファイル入出力を使い、CDNの装飾だけをローカルの代替で置き換えるため、CDNへの接続は不要です。
